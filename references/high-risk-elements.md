# High-Risk Element Registry

Always perform explicit verification on these elements.

## Text

- Chinese characters;
- similar-looking characters;
- small typography;
- dense labels;
- long single-line headings;
- technical abbreviations;
- capitalization-sensitive identifiers;
- numbers, dates, units, percentages.

## Mathematical content

- formulas;
- subscripts and superscripts;
- nested functions;
- brackets/operators;
- repeated variables.

## Geometry and topology

- arrowheads;
- dashed connectors;
- overlapping connectors;
- shared rails;
- loop closures;
- decision branches;
- incomplete borders;
- clipped containers;
- repeated symbols/icons.

## Layout

- intentional line breaks;
- alignment-critical labels;
- high-salience headings;
- hierarchy between title/module/card/body;

## Editing policy

If an edit touches or sits near a high-risk element:

- reduce the edit mask/scope;
- lock the canonical content;
- perform differential verification;
- prefer deterministic overlay/object editing.
