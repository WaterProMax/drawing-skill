# Deterministic Escalation Policy

Generative image editing is not the default solution for every technical visual.

## Escalation triggers

Escalate when any is true:

- exact formula rendering is required;
- exact Chinese text remains unstable;
- the task requires object-level preservation;
- connector topology is dense or safety-critical;
- repeated local edits keep causing regressions;
- a locked single-line heading cannot be preserved;
- a border/arrow/line must be completed precisely;
- more than two local generative repair attempts fail;
- the source is already SVG/Figma/PowerPoint/HTML or another editable format.

## Preferred methods

Use the least complex deterministic method that satisfies fidelity:

1. edit the original vector/document objects;
2. SVG or diagrams-as-code;
3. HTML/CSS;
4. Figma/PowerPoint/document drawing tools;
5. deterministic text/formula overlay;
6. structured layout engine;
7. raster patch composed from deterministic elements.

## Hybrid rule

Generative models may still assist with:

- background motif;
- non-critical illustration;
- style exploration;
- icon ideation.

But exact text, formulas, topology, and locked geometry remain deterministic.

## Communication

When escalating, state:

- which reliability requirement pure image generation cannot guarantee;
- which deterministic method is chosen;
- which visual properties remain governed by the AICareer baseline.

Do not conceal the limitation by repeatedly regenerating the full image.
